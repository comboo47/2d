# 四幕关卡与剧情大纲：秘境成长到宗门复仇

## 核心方向

- 类型基调：修仙 Rouge Lite，主线固定 + 支线随机。
- 战斗推进：章节节奏参考《暖雪》，第二幕和第三幕使用类似《哈迪斯》的清房间、选路线、拿奖励结构。
- 故事主轴：宗门被袭，主角在师兄弟保护下逃入宗门秘境，通过秘境历练成长，随后走出秘境猎杀反派势力，最终回到宗门复仇。
- 轮回解释：宗门仙器或秘境核心保住主角一缕神识，死亡或通关后回到袭宗之夜，并保留部分成长。

## 幕间推进

- 第一幕让师兄弟保护主角逃亡，承担情绪铺垫；路上可击落宝箱、遭遇人型怪物、获得基础功法。
- 第二幕不夺回宗门，而是在秘境中恢复和成长；奖励偏修仙资源，敌人偏野兽和秘境生态。
- 第三幕从秘境外开始反击，逐步靠近宗门核心战场；奖励切换到灵器法宝和Build强化。
- 第四幕才进入宗门主战场，集中烘托宗门沦陷、复仇和大师兄决战。
